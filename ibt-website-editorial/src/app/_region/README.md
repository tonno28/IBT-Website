# Regionalseiten — ausgebaut

Die drei Seiten (Köln, Aachen, Düren) waren Doorway-Seiten: derselbe Text
mit ausgetauschtem Städtenamen. Google wertet solche Seiten aktiv ab, weil
sie keinen eigenen Inhalt haben.

Der Ordner heißt deshalb `_region` — der Unterstrich macht ihn im Next.js
App Router zu einem privaten Ordner, die Seiten werden nicht mehr gebaut.

Wenn regionale Sichtbarkeit gewünscht ist, ist der Weg nicht eine Seite je
Stadt, sondern eine Seite mit echtem Ortsbezug: konkrete Projekte, lokale
Gebäudetypen, Ansprechpartner vor Ort. Bis dahin trägt die Region-Angabe im
Footer und in den Metadaten die lokale Auffindbarkeit.
